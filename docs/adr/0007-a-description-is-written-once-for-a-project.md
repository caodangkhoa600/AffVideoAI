# A description is written once for a Project

When a language model writes a Project's Storyboards, the description a generated Scene's Still or Clip is made from is written once, for the Project, the creative template and the Scene of that template, and every later writing and every Variant uses it as it is. Writing a Storyboard again rewrites its words and never its descriptions. We chose this over a fresh description with each writing because a Scene uses an approved Still or Clip again only when its description is the same, and a Clip is the most expensive thing a Project makes: fresh descriptions would have left every paid Clip behind at each rewriting and each new Variant. A description depends on the Product and the audience, which are the Project's, and not on the Hook, which is the Variant's.

## Consequences

- Asking for a Storyboard to be written again does not change its pictures. A member who wants another picture edits the description or asks for another Still, as before.
- A description that rests on a Fact which is no longer Confirmed, or no longer among the Facts the Storyboard shows, is written again at the next writing. The Stills and Clips made from the old one are kept and Flagged for Review.
- The mock planner keeps the creative template's own description. A Variant written by the mock planner and one written by a language model therefore show different pictures, and their Clips are paid for separately.
- The model is asked for a description only when the Project has none for that Scene, so most writings write words alone.
