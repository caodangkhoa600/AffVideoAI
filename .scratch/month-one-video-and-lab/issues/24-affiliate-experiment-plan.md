# 24: Affiliate experiment plan

**What to build:** A written plan the founder can follow to run the first experiment: 10 Products, 30 Variants (three per Product, one per creative template or Hook), posted by hand and tracked in the Affiliate Lab.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Product selection criteria are stated
- [ ] The plan says how Hooks and creative templates are varied so that results can be compared
- [ ] The publishing routine is described step by step, including one affiliate link per Published Post where the programme allows
- [ ] It states which metrics are recorded, when, and from which source
- [ ] It defines the review routine and what counts as enough data to draw a conclusion
- [ ] Assumptions are marked as assumptions; no market figures are presented as verified without a source
- [ ] Attribution limits are stated plainly
- [ ] The plan uses the vocabulary in `CONTEXT.md`
